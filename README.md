# anime-automation_-api:
This project is related to automating the backend api response

**##Technical Used :**
1. API used : Restful API
2. Language : Javascript
3. Framework : BDD cucumber , POM
4. Test runner : playwright

**#Setup Process:**
1. Installed node :npm init -y , npm install 
2. Installed playwright tool :  npm install --save-dev @playwright/test, npm install --save-dev @cucumber/cucumber ,npm init playwright@latest , npx playwright install 
3. Assertion :  npm install -D chai
4. Report Generation :  npm install -D multiple-cucumber-html-reporter  
5. feature files and step definitions : npm install -D playwright-bdd
